# 레퍼런스 직접 확인 기록

확인일: 2026-09-17. Chrome 브라우저에서 페이지를 열고 화면 캡처, 버튼 클릭, 대상별 탭 전환, 스크롤 및 서브페이지를 확인했다. 아래 관찰 사실과 프로젝트 설계값을 구분한다.

## Montage — 관찰 사실

- https://montage.wanted.co.kr/docs/foundations
- https://montage.wanted.co.kr/docs/components
- https://montage.wanted.co.kr/docs/utilities
- https://montage.wanted.co.kr/docs/foundations/base-material/typography
- https://montage.wanted.co.kr/docs/components/actions/button/design

흰 바탕, 좌측 문서 탐색·중앙 본문·우측 목차의 정보 위계를 확인했다. 제목과 짧은 소개 뒤에 충분한 간격을 두고 리스트·표·컴포넌트 예시가 이어진다. 전체 문서 페이지를 사이트 메인 레이아웃으로 복제하는 방식은 사용하지 않았다.

Typography 문서의 Display 1은 56/72px, Display 2는 40/52px, Title 1은 32/44px, Title 3은 24/32px, Body 1 Normal은 16/24px, Label 1 Normal은 14/20px이다. 기본 서체로 Pretendard JP를 설명한다.

Button 문서에서 Solid → Outlined 라디오를 실제로 클릭하여 예시 버튼의 변형을 확인했다. Primary/Assistive, 아이콘 배치, 상태·크기·로딩·행동 우선순위를 구분하고 있다. Utilities에서는 FocusScope, DismissableLayer, Form, Label, Grid, ScrollArea 등 공통 행동 및 레이아웃 계층이 별도 구성임을 확인했다.

적용: 한국어 Pretendard, 16px 기본 본문, 14px 보조 정보, 24/32/36px 제목과 히어로의 가변 크기, 고정 높이 버튼, 채움/외곽선 액션, 구분선 중심 목록, 명확한 선택 탭·배지·피드백. React용 Montage 패키지를 PHP 프로젝트에 설치한 것은 아니며, 직접 확인한 규격과 행동을 본 프로젝트의 CSS/Vanilla JS 컴포넌트로 구현했다. 그린 팔레트는 사용자 지정 제안값이다.

## K-클럽 — 관찰 사실

https://k-club.kird.re.kr/ 와 `/career/sub08_02.do` 직접 확인.

- 로고/유틸리티와 GNB로 구성되는 2단 헤더. 1716px 뷰포트에서 `#top_layout` 높이 172px 측정.
- 메인은 큰 좌측 배너, 작은 배너 2개, 우측 검색/로그인 패널의 조합이다. 이번 확인에서는 주요 배너 이미지가 로딩됐다.
- 현재 슬라이드 수, 이전·다음·정지 버튼을 확인하고 정지 조작을 실행했다.
- 원형 바로가기 6개와 옅은 청색 배경의 큰 흰색 대상별 서비스 패널을 확인했다.
- ‘재직자’를 클릭하면 설명과 연결 서비스가 바뀌었다.
- 공지사항/커뮤니티 2열, 하단 콘텐츠 카드, 패밀리사이트가 있다.
- 스크롤 후에도 2단 헤더가 상단에 남는 화면을 확인했다.
- 소개 서브페이지에는 실사형 배너, 경로, 큰 제목, 공유·인쇄 도구와 설명 본문이 있다.
- 모바일 390px에서 전체 GNB 대신 전체메뉴 버튼이 나타남을 확인했다. 전체 모바일 메뉴 내부 조작 전부를 확인한 것은 아니다.

적용: 2단 헤더, 6개 서비스 위계, 대상별 탭과 흰 패널, 소식 2열을 스포츠 기관에 맞게 재구성. 검색은 독립 페이지, 로그인은 전용 데모 화면으로 분리했다. 배너·로고·문구·인물 사진을 가져오지 않았다.

## BFC — 이번 확인 성공

https://www.bfc.or.kr/Index 가 인증서 우회 없이 정상적으로 열렸다. 초기 지시서의 접속 실패 상태는 이번 환경에서는 재현되지 않았다.

- 대형 자연 실사 비주얼에 흰색 투명 헤더와 중앙 영문 대형 타이틀이 배치되어 있다.
- 로고, 5개 GNB, SNS·언어·로그인·전체메뉴 원형 버튼을 확인했다.
- 전체메뉴 클릭 시 흰 배경 위 5열 카테고리 및 하위 링크가 열리고 닫기 버튼이 나타난다.
- 메인 문서에는 번호가 붙은 알림마당/주요사업/로케이션/추천지원작/소셜미디어와 패밀리사이트가 있다.

적용: 실사가 주도하는 넓은 히어로와 대메뉴 전체를 조망하는 5열 메뉴. BFC의 공식 성과 수치, 로고, 영상, 원고는 사용하지 않았다. BFC의 모든 하위 화면 및 모바일 상호작용까지 동일하다고 주장하지 않는다.

## 프로젝트 설계값 (레퍼런스 실측값 아님)

콘텐츠 최대 1320px, 데스크톱 좌우 최소 48px, 모바일 20px, 84+58px 헤더, 540px 히어로, 88px 섹션 간격을 기본으로 설계했다. 모바일에서는 74px 단일 헤더, 3×2 바로가기, 터치 슬라이드, 세로형 폼을 사용한다. UI/UX Pro Max의 2차 검색 `institution clean accessible editorial`에서 확인한 Minimalism & Swiss Style의 정렬·대비·절제된 모션 지침을 보조로 적용했다. 색상과 서체는 사용자 지정값이 우선이다.

## 미제공 자료

HWPX 원본, C시안 이미지, A/B/C/D 원본, 공식 CI, 회장 인사말, 연락처, 정관, 협회 명단, 후원사 명단, 집행 금액 미제공. 첨부 `pasted-text.txt`의 전체 메뉴와 상세 명세를 기준으로 제작했다. 이를 원본 HWPX 자체를 검토한 것으로 표현하지 않는다.

캡처는 `docs/screenshots/` 참조. 조사 화면의 기본 뷰포트와 명시적 검증 뷰포트가 섞여 있으므로 동일 배율 실측 비교 자료로 사용하지 않는다.
