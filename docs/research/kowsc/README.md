# KOWSC 원문 콘텐츠 반영

사용자가 원본 사이트의 저작권 보유 및 리뉴얼을 위한 원문 이관 권한을 명시했다. 기존 요약 이관 제한은 해제했다.

## 반영 범위
- 기사 145건, 게시판 14건의 전체 content 문자열을 원문 그대로 저장했다. 원본 API 응답은 raw/에 있으며, SHA-256으로 본문 일치를 검사한다.
- 소개 5종(인사말, 연혁, 조직도, 시·도 체육회장, 임원소개)은 원본 HTML의 문장·순서를 보존하고 현재 디자인으로 표시한다.
- 원본 기사 화면과 같이 줄바꿈 및 본문 이미지 위치를 유지한다. 원본에 포함된 마크다운 기호도 임의로 편집하지 않는다. 대표 이미지도 원본처럼 본문 앞에 유지한다.
- 원본 HTML의 인라인 스타일·클래스·스크립트는 가져오지 않는다. 현재 프로젝트 타이포그래피·색상·간격을 적용한다.
- 기존 게시물 ID·라우팅·게시판 분류·관리자 편집 기능을 유지한다. 관리자가 본문을 수정한 경우 수정 본문이 우선한다.
- 원문 링크에만 의존하던 본문, 요약 인사말, 임의로 추가한 서명을 교체했다. 화면에 수집/이관 안내는 추가하지 않았다.

## 자산 상태
167개 고유 이미지 주소 중 44개 로컬 확보. 123개는 확보 실패: cdn.kowsc.org DNS 실패 101개, 구 도메인의 이미지 요청에 HTML 응답 22개. 본문에서 원본 주소를 보존하며 기존 이미지 오류 대체 처리를 사용한다. full-content-manifest.json에 정확한 URL 및 오류를 기록했다. 이 123개 이미지는 원본 파일 확보 또는 원본 호스트 복구가 필요하다.

## 재생성
`python scripts/import-kowsc-content.py`는 저장한 원문 응답으로 다시 생성한다. `--refresh`는 현재 매핑된 159개 공개 상세와 소개 5종의 응답을 갱신한다. 새 게시물 발견이나 자동 게시 작업은 하지 않는다. 인증/관리자 API는 접근하지 않는다.

## 검증
원문 159건 문자열 및 해시 일치, 소개 5종 원본 일치, 안전한 HTML, 관리자 수정 우선순위 및 기존 검사 포함 39개 테스트. 브라우저에서 인사말 전체 문장 일치, 소개 5종·장문 기사·이미지 기사·갤러리의 표시를 확인했다.
