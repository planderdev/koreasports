# 스포츠 이미지 정리

Unsplash 스포츠 키워드 검색 및 개별 사진 페이지의 무료 라이선스·사진가 확인 후 10장 추가. 출처 URL, 사진가, 다운로드 URL, 실제 크기는 sources.json에 기록했습니다. 로컬 WebP 및 800px 이하 보조 이미지를 제공합니다.

- 메인 히어로: 테니스 / 농구 코트 / 수영. 오버레이 없이 검은 텍스트 적용.
- 비전 1·2: 러닝 / 사이클. closing 패럴렉스: 노을 속 승마.
- 주요사업 협력 카드: 농구 코트 / 사이클 / 수영.
- 대회운영 분야 카드: 축구 / 골프 스윙 / 테니스.
- 대회·동호회·자원봉사: 종목별 사진 풀에서 순환 선택. 첫 대회와 첫 동호회에 다른 사진 적용.
- 교육: 골프·펜싱·승마·풋살의 잘못된 종목 사진 매핑 수정.
- 일반 소개 화면: 페이지 주제별 이미지 매핑으로 기존 공통 골프 사진 제거.

기존 원본 게시물, 현장갤러리, PDF 행사 기록 이미지는 보존했습니다. 관리자에서 별도로 저장한 콘텐츠는 덮어쓰지 않습니다. 같은 종목 사진의 제한적 재사용은 유지하며, 제목이나 본문을 바꾸지 않았습니다.

검증: npm test 51/51, JS 구문 검사. 1440×960 / 390×844 메인 및 대회운영 화면, 비전2 이미지 로딩, 가로 overflow 확인. 대회운영 화면 캡처를 함께 보관합니다.
